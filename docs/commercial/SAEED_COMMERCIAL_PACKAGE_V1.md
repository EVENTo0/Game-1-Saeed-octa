# SAEED ROYALE Commercial & Handoff Package v1

## SKU

**SAEED-ROYALE-WEB-V1**

Price: **CUSTOM_QUOTE (AED)**

No default EVENTO daily-operations fee.

## Base package

The base package delivers one customer-specific SAEED ROYALE web deployment with:

- Arabic RTL + English interface;
- touch/mobile and desktop controls;
- static production build;
- bounded branding/content customization;
- customer-owned domain/static-host target;
- deployment + rollback instructions;
- acceptance verification tied to the reviewed source revision;
- 14-day defect warranty;
- 7-day handover support.

## Customer ownership

After accepted handoff, the customer controls:

- domain / hosting account;
- customer-specific brand assets;
- campaign/business content;
- daily operation of the delivered game.

EVENTO does not operate the customer's daily campaign/game activity by default.

## EVENTO reusable IP

Unless a separate written contract explicitly assigns it, EVENTO retains reusable generic SAEED ROYALE framework/gameplay code, reusable engineering patterns, and unrelated EVENTO systems.

This retention must not prevent the customer from operating the accepted delivered build independently.

## Explicit exclusions

Not included unless separately quoted:

- iOS/Android store packaging;
- multiplayer/backend/accounts;
- new gameplay systems or new world/map systems;
- third-party copyrighted assets;
- hosting/domain/ad-spend/vendor fees;
- guaranteed engagement, marketing or revenue performance;
- EVENTO daily operations;
- EVENTO control-plane assets or unrelated repositories.

## Customization matrix

### Safe default customization

These are normal package customizations, implemented and re-tested before handoff:

- original customer logo/brand treatment;
- title and approved campaign copy;
- colors/theme treatment;
- original customer-supplied or EVENTO-created assets with recorded rights;
- difficulty/rule tuning within existing game systems;
- deployment/domain settings.

### Requires a new quoted scope

- new gameplay mechanics;
- new map/world architecture;
- multiplayer;
- user accounts/backend;
- native mobile packaging;
- new licensed third-party art/audio/content.

### Forbidden

- copying protected third-party game assets/expression;
- shipping assets without clear commercial rights;
- removing required third-party license notices;
- claiming an untested platform/build is supported.

## Asset/license boundary

The current repository's `LICENSES.md` records:

- Three.js runtime: MIT;
- Vite: dev only, MIT;
- Vitest: dev only, MIT;
- Playwright: dev only, Apache-2.0;
- current game characters/world/weapons/UI/audio/textures are original or generated in code;
- no downloaded runtime model/texture/audio asset pack is currently required.

Any future external asset must be added to the license register before release.

## Delivery evidence

A customer handoff must record:

- source commit;
- production build reference;
- CI run;
- unit test result;
- browser/mobile smoke result;
- production dependency audit;
- license boundary result;
- deployed customer URL/domain;
- acceptance date;
- rollback source/artifact.
